# 麦当劳门店排队仿真

本项目以麦当劳门店的就餐高峰为场景，结合实地观测数据与离散事件仿真，研究顾客从到店、点单、取餐到就餐离开的服务过程。重点关注点单机和座位等有限资源如何影响顾客等待，并通过情景实验比较不同配置下的系统表现。

## 项目内容

- **观测数据与输入分析**：整理顾客和外卖员到达、点单机操作、订单完成及就餐记录，保留数据来源，分析分布特征和异常记录。
- **服务流程仿真**：用 Python 实现事件驱动模型，描述点单机排队、取餐、堂食占座和离开过程，分别记录等待、停留与资源使用情况。
- **配置与敏感性实验**：比较点单机数量、座位容量及输入数据选择的影响，生成统计摘要、图表和可追溯的事件日志。

完整流程为：**观测数据 → 整理与输入分析 → 服务流程仿真 → 情景比较 → 结果可视化**。

## 快速开始

使用 Python 3.13，在仓库目录执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -B run.py --output results/run
```

程序会依次运行测试、输入分析和仿真实验。完成后，用浏览器打开 `results/run/report.html` 查看结果；同目录保存图表、逐次实验结果和事件日志。

如需先做快速检查，可以运行：

```bash
python -B run.py --smoke --output results/quick-check
```

每次运行使用新的或空的输出目录。仓库已包含运行所需的标准化观测数据，无需原始工作簿或 AnyLogic。

## 代码组织

| 文件 | 作用 |
| --- | --- |
| `data/` | 标准化观测数据、到达记录及来源对应关系 |
| `prepare.py` | 从原始工作簿和 Notebook 提取数据，供持有原始材料时重新整理使用 |
| `analyze.py` | 描述统计、分布拟合与输入诊断 |
| `simulate.py` | 离散事件模型、资源管理与情景实验 |
| `config.json` | 资源配置、实验参数及模型假设 |
| `run.py`、`report.py` | 串联完整流程并生成本地结果报告 |
| `tests/` | 检查数据转换、排队行为和资源守恒 |

## 项目说明

本项目源于课程中的门店服务系统仿真。作者在原课程项目中主要负责数据采集和 AnyLogic 建模；本仓库中的 Python 实现、测试和文档为后续在 AI 工具辅助下完成的重建工作。原始课程报告和 AnyLogic 文件保留在本地。

当前实验用于比较给定数据与模型假设下的情景，尚未经过真实门店效果验证。具体假设与适用范围见方法文档。

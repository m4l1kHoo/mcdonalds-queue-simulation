麦当劳排队课程项目重建结果

课程项目。项目所有者确认主要负责原始数据采集和 AnyLogic 建模。本次数据流程、诊断修复、Python 参考模型、测试与文档属于新增工作。

Python 数据到结果流程已运行。此报告展示新参考模型的条件性实验，不能视为旧 AnyLogic 结果复现或真实门店改进效果。AnyLogic 材料保留在本地，不在本仓库交付范围内。

本次实际运行

使用 Python 3.13.5；固定种子 20261016，6 个情景，每个 100 次，共 600 次运行。到达序列固定为周六表中的 56 组记录，包含顾客、外卖员及一组观察到的离开者。观察窗口 60 分钟，随后停止新到达并排空已有顾客。

测试结果：17 passed, 14 warnings in 1.66s。输入校验与代码版本见 运行记录，完整假设见 各情景配置。

数据诊断的实质发现

  • 原始数值分钟按用户确认乘以 60。表头明确标为秒的列保留秒，时间戳和 Excel 日小数分别解析。
  • 66 条订单到完成记录均保留，平均 174.030 秒，最大 564 秒。IQR 规则标记 3 条；基线没有删除。
  • 8 条周六机器操作记录平均 88.666 秒；旧 Notebook 的 45 条记录平均 217.067 秒，样本来源不能确认相同，分别建模。
  • 叫号系统第二表保留了 3 条负间隔和 10 条缺失间隔。Notebook 对前三条使用了不同正值；新版没有擅自修正或把两个来源混合。
  • 旧 Q–Q 图最后一点取概率 1，产生无穷大。已改为 (i−0.5)/n，图形尾部问题不能直接证明观测异常。
  • 订单到完成序列的一阶样本 ACF 为 0.692。新版计算原观察值的 ACF；参考仿真的独立经验抽样没有保留这种相关性，其结果只能在该假设下解释。
  • 订单号前缀 35/39 的比例可以核查，但“手机/机器”类别的含义缺少表头佐证。16/66 只作为未知点单方式的显式暂定参数。

拟合结果包含同一样本内的 AIC/BIC、KS 距离及部分分布的重新拟合自助检验。自助检验按 IID 连续假设计算，未校正观察依赖、舍入和完整记录筛选。统计方法参考。没有以最小指标自动选择唯一“正确分布”。

参考模型实际流程

观察到达组 → 已记录或按显式概率分配点单方式 → FIFO 点单机 → 经验订单完成延迟 → 取走或 FIFO 等待整组座位 → 就餐 → 离开。外卖员使用独立取餐延迟路径。没有额外厨房容量约束；订单完成延迟已包含历史拥堵，不能再把它当成纯制作时间叠加厨房排队。

等待时间、食物可取时间和系统逗留时间分别记录。系统逗留时间包含就餐，不能称为“排队等待时间”。先保存观察窗口结束时的未完成顾客，再排空计算完整入场群体统计。报告同时保留受窗口限制的停留时间与仅已完成顾客的均值。

假设与适用范围

原始材料没有足够信息唯一确定预点单剩余时间、放弃等待、初始占座、订单与人数的对应关系。因此参考模型采用配置中列出的假设。跨日期数据被用于不同处理环节，结果是课程模型实验，尚未获得外部观察验证。

展开全部可配置假设
  • arrivals：Replay Saturday 12:07 onward, one record per observed group; fixed arrivals in every replication. Horizon is a new 60-minute experimental window, not a confirmed original closing time.
  • initial_state：Empty system; pre-existing customers and occupied seats are unknown. No warm-up deletion for this finite trace experiment.
  • groups：One order per group, one kiosk per order, atomic seats for the whole group, one sampled dining duration shared by that group. Missing group size explicitly imputed as 1.
  • ordering：A recorded machine use forces kiosk use. For unrecorded cases, 16/66 is a provisional probability based on historical order-prefix interpretation; not confirmed phone/kiosk ground truth.
  • dining：Use observed selection flag when present; otherwise use 47/80 from historical notebook. Flag is interpreted as intended dining, not guaranteed realized dining.
  • food_delay：Order-to-completion duration is a proxy for remaining food delay after ordering (or on arrival for non-kiosk parties and couriers). It includes historical congestion; no additional kitchen queue is added. Preordering remaining times cannot be calibrated.
  • resources：FIFO kiosks; strict FIFO group seat queue after food ready, no pre-reservation. No abandonment unless patience explicitly set. Kitchen/courier pickup counters are not capacity modeled.
  • uncertainty：Intervals describe Monte Carlo variability conditional on this trace, empirical samples and assumptions; no input uncertainty or external validation.
  • relationship：New Python reference model; not an execution-equivalent translation of the historical ALP. Differences must remain explicit.

与原 AnyLogic 项目的关系

原 ALP 及未运行验证的修订候选保留在本地，不随本仓库发布。原模型中的满座分流、提前占座、条件概率、到达参数及超时解释尚未完成逐项验证；Python 参考模型与原模型的运行等价性也尚未验证。此报告仅记录 Python 实验。

# 数据和参考仿真方法

## 数据集与选择

`order_completion`：66 条订单到达至完成的时间戳差，秒。该差值包括历史等待与处理，不能识别厨房纯服务时间。对应 Notebook 第一组 66 对时间戳完全一致，因此只计一次。

`call2_elapsed`：第二叫号表 B、C 列数值差乘以 60。62 行中 49 条非负数值间隔、3 条负间隔、10 条缺失。列事件标签缺失，数值有效不代表可与订单完成时间互换。前三条 Notebook 使用不同正值，不擅自倒置或校正原表。

`call_to_pickup_evening`：实际日期时间差。跨日跳变、负间隔和缺项单独保留，不取模 24 小时。其观测日标题与单元格日期也不一致，不拼接为统一时段。

`kiosk_service_saturday` 和 `kiosk_service_evening`：表头为秒的操作时长，分别 8、2 条。不同日期不默认合并。`kiosk_notebook` 为 45 条十进制分钟数组，来源未完整对应，作为另一输入情景。

`dining_duration`：15 条 Excel 日小数差 × 86400，按原始秒分辨率四舍五入；同时保留显式分秒文本及与其差异。部分记录可能对应同行/桌组，不认定为独立个人时长。

`pickup_to_leave_sunday`：8 条从取餐至离开的时间，不与就餐时长合并。`seat_delay_notebook` 38 条数组也不能仅凭名称认定为放弃等待的耐心时间。

`customer_group_interarrival`、`courier_group_interarrival` 分别在同一观测段、同一类型内求相邻组到达之差。分钟舍入产生零间隔，保留；不为适配连续分布而静默删零。仿真直接重放观察序列，不强行用 Gamma 到达过程替代它。

二元数据保留 `pick_leave_flag`、`after_arrival_notebook`、`dine_in_notebook` 和订单前缀类别。前两组 80 项逐项互补，但“pick - leave”不直接证明就是提前/到店点单。订单号前缀 35/39 的 50/16 计数是事实，其手机/机器解释尚需补证。

准备脚本遍历所有工作表，明确跳过模板示例行、汇总行、空白占位行、署名和无关自由文本。进入模型的子集及字段选择写在代码和以上说明中，不宣称全部表格字段都已建模。

## 输入诊断

数值时长统一使用秒。基线使用 `status == valid` 的所有观察。这个状态只表示通过当前数值检查，不证明事件含义、采样代表性或独立性已经确认。

IQR 敏感性在每个数据集内，用线性插值的 25% 和 75% 分位数确定边界 `Q1 − 1.5 IQR`、`Q3 + 1.5 IQR`，保留边界上的值。全量记录始终保留，筛选名单另存。不能比较筛选前后不同样本上的 AIC 来宣称筛选正确。

对不少于 5 条、全部正值且有变化的时长，比较 Gamma、对数正态、指数、正态和均匀分布。前三者位置固定为 0，分别估计 2、2、1 个参数；正态和均匀估计 2 个参数。AIC = 2k − 2logL，BIC = k log n − 2logL。均匀分布支持域依赖参数，普通 AIC 的常规解释受限；其值仅描述性保留，不自动排名选型。

Q–Q 绘图位置为 `(i−0.5)/n`；经验 CDF 为 `i/n`。每个拟合均检查理论 Q–Q 坐标有限。正态拟合记录负时长概率，不用于默认参考仿真。

原始保留顺序的样本 ACF 定义为：中心化数据的滞后乘积之和除以总平方和。没有用随机生成数据来证明原数据独立。间隔缺失、未知 Notebook 采样顺序等使其只能作为诊断。

三个主要数据集的四类非均匀候选分布另计算重新拟合的参数自助 KS 诊断：拟合观察、生成同长度样本、重新拟合、比较 KS 距离，p = (超越次数 + 1)/(重复次数 + 1)。默认 199 次，分辨率 0.005。此诊断依赖 IID 连续假设，未反映舍入与相关性，不充当已验证独立分布的证明。筛选后不报告未经选择校正的 p 值。[SciPy 方法说明](https://docs.scipy.org/doc/scipy-1.15.3/reference/generated/scipy.stats.goodness_of_fit.html)。

## 新 Python 参考模型

它沿用课程项目中的点单、取餐、就餐和资源问题，但采用新的、明确的事件流程。它不是原 ALP 的执行等价翻译。

每条到达记录为一个组，使用人数 `g_i`、到达时刻 `a_i`、是否机器点单、是否堂食及三个处理时长。表内明确的机器使用/堂食标记优先，缺失值按 `config.json` 的显式规则填充。独立随机抽样和跨日输入组合是实验假设。

1. 点单机 FIFO：有空闲机器时开始点单，否则按到达顺序等待。一组占用一台机器，代表“一组一单”的假设。机前等待 = 开始点单 − 到达。
2. 点单完成后，或非机器点单者到达时，开始经验订单完成延迟。外卖员也采用该延迟作为未能单独识别的剩余等待代理。没有另加厨房资源。
3. 食物可取时，取走者离开；堂食者进入严格 FIFO 的整组座位队列。空闲座位不足时，后续小组不得绕过。实际门店是否采取该规则尚未观察验证。
4. 取得 `g_i` 个座位后就餐，完成时释放相同数量座位。默认不放弃等待。可显式配置固定等待上限以验证超时行为；不能将找座延迟拟合默认当作耐心。
5. 相同时刻的资源完成事件优先于超时，超时优先于新到达；同类事件按插入顺序。零时长允许且不会产生无限到达循环。

在任一事件后检查 `0 ≤ busy_kiosks ≤ K`、`0 ≤ occupied_seats ≤ S`。人数与组数分别检查“已到达＝已离开＋仍在系统中”。这验证内部一致性，不验证现实假设。

## 观察窗口和指标

到达窗口为 `[0,H)`，默认 H = 3600 秒，以周六第一条到达作为相对时间 0。H 是本次实验设置，原表没有完整证明观察起止与初始在场人数。初始系统为空，无预热删除。所有已入场组在 H 后继续处理直至排空，资源利用率只积分到 H。

- 完整入场群体平均逗留：所有顾客组的 `(离开−到达)` 均值，包括 H 后完成者，包含就餐。
- 受窗口限制的平均逗留：所有顾客组的 `min(离开,H)−到达` 均值。晚到者暴露时间更短，不能把该值当作一般稳态平均等待时间。
- 已完成者均值：只对 H 内完成者计算，单独标记，不替代完整群体。
- 机前等待：只以使用机器的顾客组为分母；座位等待：只以请求堂食的顾客组为分母，启用超时时含超时者实际等待。
- 利用率：H 内忙碌机器/座位数量的时间积分，除以容量 × H。

## 情景和不确定性

基线为 2 台点单机、35 个座位、全部有效样本。分别改变机器数量、座位数量、IQR 筛选、机器样本来源及缺失同行人数；不同时混入多个未说明的资源变化。

每个组预留固定数量的均匀随机数，再通过经验分位数选样。相同种子在情景间共享到达和随机数，避免某个分支未执行而错位消费随机数。每情景 100 次；配对差异用同一重复的情景值减基线值，用 t 区间汇总。

区间只描述条件性 Monte Carlo 变化，不含输入参数、观察选择、未知初始占座和结构误差。订单完成数据有明显序列相关，当前独立经验抽样忽略了它；未来应增加同一时段的完整记录后再研究相关输入、初始占座与验证误差。不能把资源情景的模拟差值外推为真实门店效果，也不能把 IQR 筛选造成的下降写成运营改进。
